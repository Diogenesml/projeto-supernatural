# Supernatural — Projeto Front-end

Landing page temática inspirada em **Supernatural**, desenvolvida como estudo de HTML, CSS e JavaScript.

> Projeto de fã, sem vínculo oficial com a série ou seus detentores de direitos.

## Recursos

- experiência visual em tela cheia
- carrossel de seis cenas
- navegação por clique e pelas setas do teclado
- estados acessíveis com `aria-pressed`
- layout responsivo
- suporte a `prefers-reduced-motion`
- links seguros para GitHub e LinkedIn

## Tecnologias

HTML5 · CSS3 · JavaScript

## Estrutura

- `index.html` — conteúdo e semântica
- `src/css/` — estilos, reset e responsividade
- `src/js/index.js` — interação do carrossel
- `src/imagens/` — assets visuais
